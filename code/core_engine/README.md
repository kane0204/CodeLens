# 核心引擎（code/core_engine）

本项目最具技术含量的部分：把代码变成可解释的结构，再据此生成分层提示与练习。

## 职责边界

| 属于本模块 | 不属于本模块 |
|---|---|
| 语法解析与语义分块、关键行识别 | HTTP 接口与鉴权（属 backend） |
| 复杂度启发式估计 | 界面与交互（属 frontend） |
| 提示分层策略与模板渲染 | 用户数据长期存储（属 backend） |
| 练习生成与测试用例构造 | 沙箱资源隔离实现（属 backend） |
| 大模型调用的提示编排（Prompt 组装与解析） | 计费与配额（属 backend） |

## 约定

- 语言：Python 3.11；解析层按语言插件化，新增语言不改动调用方；
- 对外统一返回结构化 JSON（字段定义见 `docs/software/api-contract.md`）；
- 算法设计依据 `docs/algorithm/`，实现与文档不一致时先改文档再改代码；
- 关键函数必须带单元测试（`tests/unit`），示例代码样本放入 `tests/`。
