# 核心引擎（code/core_engine）

本模块把「一个项目文件夹」变成「可渲染的图数据」，是 CodeLens 的技术核心。

## 处理流水线

```text
项目文件夹 → 扫描/语言识别 → 多文件解析 → 符号解析 → 关系图构建 → 图投影 → 导出
```

| 阶段 | 产出 | 关键点 |
|---|---|---|
| 扫描 | 文件清单、包/模块结构、语言统计 | 忽略第三方依赖与构建产物 |
| 解析 | 每文件的 AST（类、函数、导入、继承） | tree-sitter，多语言插件化 |
| 符号解析 | 名称 → 定义位置的映射 | 处理 import、别名、作用域 |
| 关系图 | 节点/边 + 源码位置 + 置信度 | 统一中间表示（IR） |
| 图投影 | 类图、调用图、模块依赖图、时序图 | 同一张图的子集视图 |
| 导出 | Mermaid / PlantUML / SVG / Markdown | 可被标准渲染器直接使用 |

## 职责边界

| 属于本模块 | 不属于本模块 |
|---|---|
| 目录扫描、语言识别、文件过滤 | 用户上传与任务鉴权（属 backend） |
| AST 解析、符号解析、类型推断 | 图的交互式展示（属 frontend） |
| 类图/调用图/时序图的构建与裁剪 | 报告排版与下载（属 backend/frontend） |
| 导出格式生成 | 运行时动态追踪（后续迭代） |

## 约定

- 语言：Python 3.11；解析层按语言插件化，新增语言不改动调用方；
- 所有图节点与边必须携带 `file` / `line` / `confidence`，没有位置信息的关系不得输出；
- 算法依据 `docs/algorithm/`，实现与文档不一致时先改文档；
- 核心函数必须有单元测试，样例项目纳入 `tests/` 回归。
