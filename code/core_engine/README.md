# 核心引擎（code/core_engine）

本模块把「一个 AI 生成的项目文件夹」变成「可读的逻辑说明 + 可渲染的图 + 可解释的风险清单」。

## 处理流水线

```text
项目文件夹
  → 扫描/语言识别
  → 多文件解析（Python ast）
  → 符号解析与调用图
  → 逻辑建模（步骤/分支/异常/数据流/副作用/假设）
  → 逻辑说明生成（纯模板 + 引用校验，无模型）
  → 结构图投影（类图/时序图/依赖图）
  → 指标与规则（复杂度/坏味/SOLID/AI 风险）
  → 健康度与证据分级
  → 报告导出
```

| 阶段 | 产出 | 关键点 |
|---|---|---|
| 扫描 | 文件清单、包/模块结构 | 忽略依赖与构建产物 |
| 解析 | 每文件 AST | 首期 Python `ast`；多语言走 tree-sitter 插件 |
| 符号解析 | 名称 → 定义位置 | import、别名、作用域 |
| 逻辑建模 | 函数/模块逻辑模型 | 七类信息；不确定项标 inferred |
| 逻辑说明 | 自然语言步骤 | 每条引用代码行；无依据不输出 |
| 关系图 | 类图/调用图/依赖图 | 统一 IR |
| 指标与规则 | metrics + findings | 规则 ID、阈值、位置、证据等级 |
| 报告 | Markdown / JSON / 图 | 按风险排序 |

## 职责边界

| 属于本模块 | 不属于本模块 |
|---|---|
| 目录扫描、语言识别、文件过滤 | 用户上传与任务鉴权（属 backend） |
| AST 解析、符号解析、类型推断 | 交互式展示（属 frontend） |
| 逻辑建模与逻辑说明 | 报告排版与下载（属 backend/frontend） |
| 图构建、指标、坏味、SOLID、AI 风险 | 运行时动态追踪（后续迭代） |

## 关键约定

- 首期语言：Python 3.11（标准库 `ast`）；解析层与规则层插件化；
- **不调用任何大模型**：输出必须确定、可复现，同一输入两次运行逐字节一致；
- **逻辑说明必须可回溯**：每个步骤携带 `file` / `line_range`，无依据的句子不得输出；
- **每条 finding 必须携带**：`rule_id`、`severity`、`file`、`line`、`actual`、`threshold`、`confidence`、`evidence_type`；
- 静态推断的结论（动态分派、副作用判断）标注 `inferred`，不得与事实混排；
- 首期 SOLID 规则：SRP-01、OCP-01、DIP-01；
- 算法依据 `docs/algorithm/`，实现与文档不一致时先改文档。

## 目录建议

```text
core_engine/
├── scan/          # 目录遍历、语言识别、文件过滤
├── parse/         # Python ast 解析器（后续多语言插件）
├── resolve/       # 符号表、类型推断、导入解析
├── logic/         # 语句轨迹、CFG、def-use 与说明模板
├── graph/         # 类图、调用图、依赖图
├── metrics/       # 复杂度与规模指标
├── rules/         # 坏味、SOLID、AI 风险
├── score/         # 健康度与证据分级
├── render/        # 图投影与导出
└── report/        # Markdown 报告生成
```
