# 前端（code/frontend）

负责项目导入、图表浏览与源码定位。

## 核心页面

| 页面 | 内容 |
|---|---|
| 项目导入 | 选择/拖入项目压缩包，展示语言识别与文件统计 |
| 分析进度 | 扫描、解析、出图各阶段进度与错误提示 |
| 图浏览 | 类图、时序图、模块依赖图切换；缩放、筛选、按模块展开 |
| 源码定位 | 点击节点展示对应源码片段（文件 + 行号）并高亮 |
| 导出 | 下载 Mermaid / PlantUML / SVG / Markdown 报告 |

## 约定

- 技术栈：TypeScript + React + 图渲染库（选型见 W3 设计文档）；
- 图数据一律通过 `src/api/` 获取，组件不做数据加工；
- 大图默认展示聚类后的模块级视图，用户点击后再展开细节；
- 推断关系与确定关系用不同线型/颜色区分，并保留图例说明。
