# 前端（code/frontend）

负责项目导入、逻辑浏览、结构图查看与风险定位。

## 核心页面

| 页面 | 内容 |
|---|---|
| 项目导入 | 选择/拖入项目压缩包，展示语言识别与文件统计 |
| 分析进度 | 扫描、解析、逻辑建模、出图各阶段进度与错误提示 |
| **逻辑视图** | 函数/模块列表 + 步骤序列；点击步骤跳转到对应代码行；展开分支与异常路径 |
| 结构视图 | 类图、时序图、模块依赖图切换；缩放、筛选、按模块展开 |
| 风险报告 | 按严重度排序的发现列表；按规则/模块/证据等级筛选 |
| 问题详情 | 规则 ID、阈值、实际值、证据等级、涉及代码行与建议 |
| 源码定位 | 点击节点或步骤，展示源码片段并高亮行 |
| 导出 | 下载 Markdown / JSON / Mermaid / PlantUML / SVG |

## 交互约定

- 逻辑视图默认展示函数摘要，点击后展开步骤，避免一次性倾倒所有细节；
- 每个步骤显示行号范围，点击即可定位源码；
- 事实、推断、说明三类结论用不同标识（图标 + 文字），不只用颜色；
- 风险列表默认按「严重度 × 置信度」排序；
- 图与报告联动：选中模块后，报告过滤到该模块；
- 所有数据来自 `src/api/`，组件不做二次推断。
