# 算法设计文档（docs/algorithm）

本目录存放 CodeLens 核心算法的设计说明、伪代码、复杂度分析与实验记录。

## 规划中的文档

| 文件名 | 内容 | 负责人 | 计划周次 |
|---|---|---|---|
| `code-chunking.md` | 代码语义分块与关键行识别：AST/tree-sitter 解析、分块策略、关键行打分 | 算法负责人 | W2 |
| `hint-layering.md` | 分层提示策略：提示层数定义、触发条件、防泄漏答案的约束 | 算法负责人 | W2 |
| `complexity-estimation.md` | 时间复杂度估计方法：循环嵌套计数与常见模式的启发式规则 | 算法负责人 | W2 |
| `exercise-generation.md` | 练习生成与测试用例自动构造、判分流程 | 算法负责人 | W2 |
| `evaluation.md` | 评估集与实验结果（准确率、命中率、成本） | 测试负责人 | W4 |

## 写作要求

1. 每个算法须给出：**问题定义 → 输入输出 → 伪代码 → 复杂度 → 边界与反例 → 实验数据**；
2. 伪代码与实现有差异时需说明原因；
3. 所有实验数据注明代码样本规模、运行环境与日期。
