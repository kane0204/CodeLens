## 统一的中间表示（IR）

所有算法共享同一份图数据 IR：节点（项目/模块/文件/类/函数）+ 边（继承、实现、组合、关联、依赖、调用）+ 位置信息（`file`、`line`）+ 置信度（`certain` / `inferred`）。

这样一来：类图、时序图、依赖图都只是对同一张图的不同**投影**，导出格式（Mermaid / PlantUML / SVG）也可以复用同一套数据。

## 写作要求

1. 每个算法须给出：**问题定义 → 输入输出 → 伪代码 → 复杂度 → 边界与反例 → 实验数据**；
2. 必须说明「哪些情况无法确定」，以及图上如何标注；
3. 实验数据注明样例项目规模、语言、运行环境与日期；
4. 与实现不一致时，先修改文档再修改代码。
