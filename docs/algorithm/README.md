## 统一的中间表示（IR）

所有算法共享同一份解析结果，包含四类数据：

1. **图数据**：节点（项目/模块/文件/类/函数）+ 边（继承/实现/组合/关联/依赖/调用）+ 位置 + 置信度；
2. **逻辑模型**：语句轨迹、CFG、def-use、分支、异常、副作用、假设；
3. **指标**：节点上的 `metrics`（复杂度、规模、耦合、内聚）；
4. **发现**：`findings`（规则 ID、严重度、位置、实际值、阈值、建议、证据等级）。

结构图是图数据的投影，逻辑说明是逻辑模型的投影，风险报告是指标与发现的聚合。三者同源，才能互相印证。

## 写作要求

1. 每个算法须给出：**问题定义 → 输入输出 → 伪代码 → 复杂度 → 边界与反例 → 实验数据**；
2. 逻辑模型必须给出**字段定义**与**抽取规则**，并说明哪些情况无法确定；
3. 指标必须给出**精确公式**与至少一个手算示例；
4. AI 风险规则必须说明**误报场景**、置信度与建议动作；
5. 实验数据注明样例项目规模、语言、运行环境与日期。
6. **不引入模型**：所有描述由模板与规则生成，相同输入必须得到逐字节相同的输出。
