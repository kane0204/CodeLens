# 产品使命、口号与策略设计

## 1. 设计产品的使命和口号

### ● 使命
解决 AI 生成代码的黑盒问题，让开发者能看懂、能验证、能审查 AI 写出的项目代码。

### ● 口号
Make Code Visible.

---

## 2. 制定产品的策略

### ● 目标用户是？
使用 AI 编码的开发者

### ● 如何争取目标用户？
核心分析全部静态完成，不依赖模型，结果 100% 可复现；
可选 LLM 用于文字说明，输出简洁，同时不影响结论。

### ● 公司/团队的优势是？
小团队迭代快，能根据真实项目反馈快速校准阈值。

#### SWOT 分析：

| | 有利 | 不利 |
|---|---|---|
| 内部 | **优势**：静态分析确定可复现；零运行时依赖；针对 AI 代码的专门规则；| **劣势**：首期仅 Python；动态调用与反射识别有限；规则阈值需校准；|
