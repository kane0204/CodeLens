# 产品使命、口号与策略设计

## 1. 设计产品的使命和口号

### ● 使命
解决 AI 生成代码的黑盒问题，让开发者能看懂、能验证、能审查 AI 写出的项目代码。

### ● 口号
Make Code Visible.

---

## 2. 制定产品的策略

### ● 目标用户是？
使用 AI 编码的开发者

### ● 如何争取目标用户？
- 首批通过高校开发者社团、开源项目和 AI 编程社群触达使用 AI 编码的开发者；
- 以免费项目扫描和可分享的审查报告作为试用入口，跟踪“渠道触达—首次扫描—团队采用”的转化；
- 先以个人版建立口碑，后续通过团队版、私有部署和定制规则探索商业化。

### ● 公司/团队的优势是？
苏州大学计算机学院课程小组，具备 Python / TypeScript、静态分析、React、FastAPI 和自动化测试开发能力；小团队迭代快，能根据真实项目反馈快速校准规则。

#### SWOT 分析：

| | 有利 | 不利 |
|---|---|---|
| 内部 | **优势**：静态分析确定可复现；零运行时依赖；针对 AI 代码的专门规则；| **劣势**：首期仅 Python；动态调用与反射识别有限；规则阈值需校准；|
