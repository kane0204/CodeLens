# 阶段复盘（docs/retrospection）

本目录保存每周及每个阶段的复盘记录，用于积累经验并指导下一次迭代。

## 复盘节奏

- 每周日晚提交 `week-XX.md`；
- 每个阶段（需求 / 算法 / 软件）结束提交 `phase-XX.md`。

## 记录模板

复制 [template.md](template.md) 使用。每份复盘必须包含四部分：

1. **计划 vs 实际**：本周承诺的任务与实际完成情况（附 Issue 编号）；
2. **数据**：可量化指标（完成任务数、缺陷数、评审轮次、构建失败次数）；
3. **问题与原因**：出现的阻塞、返工、沟通失误及根因；
4. **改进项**：下阶段的可执行改进行动（含负责人与截止时间）。
