# 软件设计文档（docs/software）

本目录存放架构、接口、数据与测试相关的设计文档。

## 规划中的文档

| 文件名 | 内容 | 负责人 | 计划周次 |
|---|---|---|---|
| `architecture.md` | 总体架构：前端 / 后端 / 核心引擎 / 沙箱的模块划分与数据流（含 Mermaid 图） | 架构负责人 | W3 |
| `api-contract.md` | REST 接口契约：路径、请求/响应字段、错误码、超时与重试约定 | 后端负责人 | W3 |
| `data-model.md` | 数据模型：用户、会话、卡点记录、练习记录，保留策略与脱敏规则 | 后端负责人 | W3 |
| `test-plan.md` | 测试方案：单元/集成/E2E 的划分、覆盖率目标、评估集使用方式 | 测试负责人 | W3 |
| `deployment.md` | 部署与运行环境、配置项、密钥管理 | 后端负责人 | W5 |

## 写作要求

1. 设计与需求对应关系须显式标注（引用 `docs/requirements/problem_definition.md` 的功能编号 F1–F5）；
2. 接口变更必须先改文档再改代码，并在 PR 中说明影响范围；
3. 架构图使用 Mermaid，便于版本对比。
