# AI 自然语言逻辑解读

“逻辑说明”已改成面向阅读的 AI 解读界面，替换原有 AST 轨迹表格和 CFG/数据流占位标签。

## 使用

1. 导入 Python 项目，进入“逻辑说明”。
2. 在设置中填写兼容 OpenAI chat/completions 的基础地址、模型名称及密钥。地址支持 `/v1` 或完整 `/chat/completions` 端点。
3. 选择项目文件，再选择“整个文件”或单个函数，点击“生成 AI 解读”。
4. 阅读自然语言说明，按引用行号展开原始源码核对。支持复制、重新生成和取消。

保存设置不会调用模型。配置全部留空时，后端尝试读取 `CODELENS_AI_ENDPOINT`、`CODELENS_AI_MODEL`、`CODELENS_AI_KEY`。自定义配置缺少地址或模型名称时直接提示错误，不混用服务端密钥。无认证的本地兼容服务可以留空密钥。

## 请求与结果

`POST /api/explain` 沿用本机 Host、Origin、令牌和请求大小检查。

请求包含 `files`（与分析接口相同的源码格式）、`target: {file, function}`、可选 `provider: {base_url, model, api_key}`。`function` 为 null 表示整个文件，否则必须是所选文件中的实际函数 ID。

后端先解析源码并校验目标，发送所选范围的带行号源码（最多 60000 字符），再沿已解析调用补充最多两层相关函数或类（最多 6 段、合计 20000 字符）。不会发送无关文件；超限段数记录在 omitted_context。未解析的动态调用不会猜测。客户端把已导入文件传给本机后端用于构建调用图，只有列出的上下文发送到模型。接口设置 include_context=false 可关闭补充上下文。

模型收到的要求包括整体用途、输入输出、执行步骤、分支循环、异常、依赖、副作用和边界，并明确区分代码可见行为与推测。解读不是事实层的确定性证明，与旧 `/api/ai` 结构化规则表达接口独立。

响应包括 `text`、`model`、`file`、`function`、`line`、`end_line`、`truncated`、`context`、`omitted_context`、`citations`。引用格式为 `[路径:L起始行-L结束行]`；后端验证引用位于本次发送的源码范围，前端仅为有效引用提供源码高亮弹窗，越界引用会标为未验证。文本经过 HTML 转义展示，不执行模型返回的 HTML。输出因长度截断时明确提示。

## 状态与数据

- 未配置、请求中、失败、超时和取消均有明确提示；失败不以模板伪装成 AI 结果。
- 后端模型调用超时 45 秒，页面等待上限 60 秒；取消页面请求不会保证撤销模型服务端已开始的生成或计费。
- 地址和模型名称存入本机浏览器；密钥仅存当前页面内存，请求时发送给本机后端，再用于所选模型服务认证。密钥不写入报告、项目文件或浏览器持久存储。
- 点击生成意味着把所选范围及相关调用上下文源码发送到配置的模型服务。普通静态分析不调用模型。
- JSON/Markdown 报告可选择包含已生成解读、模型和上下文范围；JSON 默认不包含源码。解读只缓存在当前页面，按文件/函数隔离；重新导入项目或保存模型设置后清空，迟到的旧请求结果会被忽略。

验证包含本机假模型服务与真实应用 HTTP 接口的端到端测试，以及前端解读、范围切换、文本转义、错误和旧请求隔离测试。不依赖真实服务商或密钥。
