# CodeLens 需求简报（群内讨论版）

结合群主在群内的补充要求，提炼核心需求如下：

## 一、功能性需求
1. **代码解析**：基于 `tree-sitter` 解析源码，构建代码调用图。
2. **图表生成**：支持输出 Mermaid 流程图，也可借助 `d2` 工具渲染。
3. **交互式查看器**：提供本地 Viewer，支持图表平移、缩放、下钻查看。
4. **大模型辅助**：接入 OpenAI、Gemini 等大模型后端，辅助解读代码。
5. **结果输出**：支持自定义输出目录，可配置是否自动打开查看器。

## 二、非功能性需求
1. **易用性**：提供简单 CLI，支持 pip 一键安装；提供网页在线版本。
2. **可扩展性**：多模型后端接入；解析与渲染模块解耦，便于多语言支持。
3. **可视化体验**：支持流畅的图表缩放、平移、子图钻取。
4. **可部署性**：产物本地化支持离线查看；同时提供线上独立站点服务。
