# 集成测试（tests/integration）

验证模块间协作与端到端主流程。

## 覆盖的流程（MVP）

1. 提交代码 → 返回结构化解读（`POST /analysis`）；
2. 提交代码 + 报错 → 返回第一层提示，逐层展开后得到原因与修复方向；
3. 按知识点生成练习 → 提交答案 → 沙箱判分返回结果；
4. 异常路径：超长输入、非支持语言、模型超时、沙箱超时。

## 约定

- 模型调用在 CI 中使用固定桩数据（录制回放），避免计费与不稳定；
- 每个流程用例需记录输入样例、期望关键字段与超时阈值；
- 评估集样本（`docs/mgmt/backlog.md` 中的 W2-06）在本目录中复用。
