# 集成测试（tests/integration）

验证「AI 生成的项目文件夹 → 逻辑说明 + 结构图 + 风险报告」的端到端流程。

## 覆盖的流程（MVP）

1. 扫描样例项目 → 输出文件、模块与符号清单；
2. 逻辑建模 → 输出 `logic.json`，校验 5 个样例函数的步骤、分支、异常与副作用；
3. 逻辑说明 → 输出 `logic.md`，校验每条说明都带代码位置引用；
4. 类图 → 导出 Mermaid，校验节点/边与期望一致；
5. 时序图 → 选择入口函数，校验参与者与消息顺序；
6. 指标 → 与参考实现/人工标注对拍（CC、长度、WMC、CBO）；
7. 规则 → 坏味、SOLID S/O/D、AI 风险 A1–A8 的命中集合；
8. 报告 → Markdown/JSON 字段完整，证据等级与位置齐全；
9. 异常路径：空目录、非 Python 文件、语法错误、超大项目、压缩包路径穿越。

## 约定

- 样例项目放在 `tests/fixtures/projects/`，每个项目附 `expected/`（逻辑、图结构、指标、问题集合）；
- 逻辑输出是确定性模板，按 golden file 逐字节比对；措辞变化必须显式更新期望文件；
- 图比较以结构（节点集合、边集合）为准，不比较布局坐标；
- 指标比较使用容差（默认 ±5%），记录参考实现版本；
- 规则评审以「正例全中、反例不误报」为门槛，推断类规则单独统计；
- 渲染测试固定渲染器版本，避免结果漂移。
