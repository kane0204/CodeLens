# 集成测试（tests/integration）

验证「项目文件夹 → 图产物」的端到端流程。

## 覆盖的流程（MVP）

1. 扫描样例项目 → 输出文件、包/模块与符号清单；
2. 构建类图 → 导出 Mermaid，校验可渲染且节点/边与期望一致；
3. 选择入口函数 → 生成时序图 → 校验参与者与消息顺序；
4. 生成模块依赖图 → 检出循环依赖并在图中标注；
5. 导出 PlantUML / SVG → 校验文件生成与基本合法性；
6. 异常路径：空目录、非支持语言、超大项目、语法错误文件、压缩包路径穿越。

## 约定

- 样例项目放在 `tests/fixtures/projects/`，每个项目附 `expected/` 期望结果；
- 准确率回归与 [docs/algorithm/evaluation.md](../algorithm/evaluation.md) 的标注基准保持一致；
- 图数据比较以结构（节点集合、边集合）为准，不比较布局坐标；
- 渲染类测试在 CI 中使用固定版本渲染器，避免结果漂移。
