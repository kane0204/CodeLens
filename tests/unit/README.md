# 单元测试（tests/unit）

针对解析、图构建与导出函数的测试，快速、无外部依赖。

## 覆盖优先级

1. **符号解析**：import、别名、嵌套作用域、同名符号；
2. **类图构建**：继承/实现/组合/关联/依赖的判定；
3. **调用图**：跨文件调用、方法调用、多态推断（标注为 inferred）；
4. **时序图**：调用链展开、循环/条件标注、参与者归并；
5. **导出**：Mermaid/PlantUML 语法合法（含特殊字符转义）。

## 约定

- 框架：pytest；
- 命名：`test_<模块名>.py`，测试函数 `test_<行为>_<期望>()`；
- 每个测试只验证一个行为，包含正常路径与至少一个边界/异常路径；
- 解析器测试使用 `tests/fixtures/` 下的最小代码片段。
